# City Catalog Attribution

The longitude and administrative hierarchy records in `cities.json` are derived
from the GeoNames geographical database export for China (`CN.zip`).

- Source: <https://download.geonames.org/export/dump/CN.zip>
- Provider: GeoNames, <https://www.geonames.org/>
- License: Creative Commons Attribution 4.0, <https://creativecommons.org/licenses/by/4.0/>
- Retrieved: 2026-07-24

The exact source checksum is stored in `cities.json`. The generated catalog
contains only names, administrative relationships, stable GeoNames-derived
codes, center longitudes, and GeoNames identifiers. It does not contain user
location data.
